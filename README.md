# 🌿 Afya Living

> Natural beauty, wellness and self-care inspired by nature and African wellness traditions.

Afya Living is a modern, responsive e-commerce website designed for customers looking for natural beauty, wellness and self-care products.

The project focuses on creating a clean, calming and user-friendly shopping experience where customers can explore products, browse different categories, view product details and interact with different sections of the website.

The design combines natural colors, modern layouts and African-inspired wellness themes to create a warm and welcoming digital experience.

# 🌿 Project Overview

Afya Living is a front-end e-commerce project created to showcase natural beauty, wellness and self-care products.

The website provides customers with a simple way to:

- Discover wellness products
- Browse products by category
- View product prices and ratings
- View detailed product information
- Explore skincare, hair care, wellness and gift products
- Learn more about the Afya Living brand
- Read customer testimonials
- Subscribe to a newsletter
- Contact the business
- Add products to a shopping cart

The project was created with a strong focus on clean HTML structure, modern CSS styling, responsive layouts and a user-friendly shopping experience.

---

# 🎯 Project Goals

The main goals of the Afya Living project are to:

1. Create a professional e-commerce website interface.
2. Provide customers with an easy-to-use product browsing experience.
3. Organize products into clear categories.
4. Create a visually appealing wellness-inspired design.
5. Practice semantic HTML and modern CSS techniques.
6. Create a responsive website that works across different screen sizes.
7. Build a foundation that can later be enhanced with JavaScript functionality.
8. Demonstrate practical front-end web development skills.
